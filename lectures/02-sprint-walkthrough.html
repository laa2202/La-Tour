A trade, a position, and a portfolio

Asset: something with a market price. Instrument: what we can actually buy or sell. Buy/long: benefit when the price rises, all else equal. Short: benefit when price falls, subject to costs and risk. Cash: uninvested allocation.

Position: how much you hold. Weight: fraction of portfolio capital assigned to that position. Portfolio: all holdings and cash together.

Example: $1,000 portfolio, 25% SPY = $250 invested. If SPY rises 2% and everything else is unchanged, that position contributes approximately $5, or 0.5% of the whole portfolio.

How do quants choose what to test?

  1. Find an anomaly: A widely discussed pattern is that some asset-price trends persist.
  2. Ask why: Slow information diffusion, positioning, and investor behavior are possible explanations.
  3. Write a falsifiable prediction: Assets with positive prior 12-month returns may outperform cash in the next month.
  4. Choose a measurable rule: Long if past return > 0; otherwise cash.
  5. Define failure: No improvement over a fair benchmark after costs and tests.

What exactly is momentum?

Momentum: using a prior price change as an input for future positioning. Time-series momentum: compare an asset with its own past. Cross-sectional momentum: compare assets with one another.

Past return = Price today / Price 252 trading days ago − 1

Example: historical adjusted price moves from $100 to $110 → past return = +10% → candidate long signal. It does not mean tomorrow will be positive.

How does a backtest produce returns?

Daily asset return = today's price ÷ yesterday's price − 1. A simple constant-weight portfolio return is the sum of weight × asset return.

portfolio_return[t] = Σ weight[i,t] × asset_return[i,t] − cost[t]

Example: 25% in an ETF earning +2% generates +0.5% portfolio return, before costs. A sequence of returns compounds: wealth[t] = wealth[t−1] × (1 + return[t]).

The most dangerous bug: time travel

Suppose your model uses today's closing price to decide what to hold at today's opening price. That is impossible: it uses information from the future.

Our toy reference model uses the prior close for its signal, but still assumes positions can be filled at that prior close. That makes the historical return simulation non-executable as written.

A more credible future implementation needs actual next-open data, explicit order timing, and slippage; adjusted close is not an execution price.

import csv
from pathlib import Path
import yfinance as yf

ROOT = Path(__file__).resolve().parents[1]
TICKERS = ['SPY', 'IEF', 'GLD', 'UUP']
START, END = '2010-01-01', '2026-10-10'  # End is exclusive; frozen through Oct 9, 2026.

def main():
    dest = ROOT / 'data' / 'prices.csv'
    all_rows=[]
    for ticker in TICKERS:
        df=yf.download(ticker,start=START,end=END,auto_adjust=True,progress=False,threads=False)

        close=df['Close']
        if hasattr(close,'columns'): close=close.iloc[:,0]
        for date, price in close.dropna().items():
            all_rows.append([date.strftime('%Y-%m-%d'),ticker,round(float(price),8)])
    all_rows.sort(key=lambda x:(x[0],x[1]))
    dest.parent.mkdir(parents=True,exist_ok=True)
    with dest.open('w',newline='') as fh:
        w=csv.writer(fh);w.writerow(['date','ticker','adj_close']);w.writerows(all_rows)
    print(f'Wrote {len(all_rows)} authentic observed ETF observations to {dest}. Latest date: {all_rows[-1][0]}')
    print('Check missing trading days, vendor adjustments, and price-source licensing before research use.')

if __name__=='__main__': main()

"""Common MVP evaluator: 12-month trailing signal, monthly rebalancing, long/cash, no leverage.
Inputs: date,ticker,adj_close. Calculations use signal at prior close for current-day close-to-close return.
Costs: 5 basis points per unit notional turnover. This is a teaching assumption, not an execution estimate.
"""
import csv, math, argparse
from collections import defaultdict
from datetime import date
from pathlib import Path

TICKERS=('SPY','IEF','GLD','UUP')

def read_prices(path):
    by=defaultdict(dict)
    with open(path,newline='') as f:
        rd=csv.DictReader(f)
        if rd.fieldnames!=['date','ticker','adj_close']:
            raise ValueError('Expected exact columns: date,ticker,adj_close')
        for row in rd:
            dt=date.fromisoformat(row['date']); ticker=row['ticker']; p=float(row['adj_close'])
            if ticker not in TICKERS or not math.isfinite(p) or p<=0: raise ValueError('Invalid row '+str(row))
            if ticker in by[dt]: raise ValueError('Duplicate date/ticker')
            by[dt][ticker]=p
    dates=sorted(d for d,r in by.items() if len(r)==len(TICKERS))
    if len(dates)<280: raise ValueError('Need at least 280 common trading dates')
    if any(len(by[d])!=4 for d in dates): raise ValueError('Unexpected missing values')
    return dates,by

def backtest(path,output,lookback=252, fee_bps=5):
    dates, px=read_prices(path)
    out=[]; positions={t:0.0 for t in TICKERS}; prev_signal=None
    prev_month=None
    for i in range(lookback+1,len(dates)):
        d=dates[i]; yesterday=dates[i-1]; lookback_d=dates[i-1-lookback]
        # At close yesterday, use only prices observed at or before yesterday.
        # Set target weights for the current day; rebalance only on the first trading day of each month.
        desired={t:(0.25 if px[yesterday][t]>px[lookback_d][t] else 0.0) for t in TICKERS}
        month=(d.year,d.month)
        traded=month!=prev_month
        if traded:
            turnover=sum(abs(desired[t]-positions[t]) for t in TICKERS)
            positions=desired
        else: turnover=0.0
        gross=sum(positions[t]*(px[d][t]/px[yesterday][t]-1) for t in TICKERS)
        cost=fee_bps/10000*turnover
        net=gross-cost
        bench=sum(.25*(px[d][t]/px[yesterday][t]-1) for t in TICKERS)
        out.append({'date':d.isoformat(),'net_return':net,'benchmark_return':bench,
                    'gross_return':gross,'cost':cost,'turnover':turnover,
                    **{f'weight_{t}':positions[t] for t in TICKERS}})
        prev_month=month
    output=Path(output);output.parent.mkdir(parents=True,exist_ok=True)
    with output.open('w',newline='') as f:
        wr=csv.DictWriter(f,fieldnames=out[0]);wr.writeheader();wr.writerows(out)
    rets=[x['net_return'] for x in out]
    annual=(math.prod(1+r for r in rets)**(252/len(rets))-1) if all(1+r>0 for r in rets) else float('nan')
    mu=sum(rets)/len(rets); vol=math.sqrt(sum((r-mu)**2 for r in rets)/(len(rets)-1))*math.sqrt(252)
    sharpe=(mu*252/vol) if vol else float('nan') # assumes zero risk-free return
    wealth=1;peak=1;maxdd=0
    for r in rets:
        wealth*=1+r;peak=max(peak,wealth);maxdd=min(maxdd,wealth/peak-1)
    print(f'Days: {len(out)} | CAGR: {annual:.2%} | Ann vol: {vol:.2%} | Sharpe (rf=0): {sharpe:.2f} | MaxDD: {maxdd:.2%}')
    print(f'Output: {output} | Dataset: {path}')
    return out

if __name__=='__main__':
    ap=argparse.ArgumentParser();ap.add_argument('--input',required=True);ap.add_argument('--output',default='results/backtest.csv');ap.add_argument('--lookback',type=int,default=252);ap.add_argument('--fee-bps',type=float,default=5)
    a=ap.parse_args();backtest(a.input,a.output,a.lookback,a.fee_bps)

How daily P&L is calculated

grossₜ = Σᵢ wᵢ,ₜ · rᵢ,ₜ
turnoverₜ = Σᵢ |wᵢ,ₜ − wᵢ,ₜ₋₁|
netₜ = grossₜ − 0.0005·turnoverₜ

The fee is a toy assumption of five basis points per unit traded, not a broker quote or estimated market-impact model.

Read the risk report

CAGR

Annualized compounded net wealth growth; sensitive to starting/ending dates.

Sharpe

Annualized mean divided by volatility; this toy version assumes zero risk-free rate.

Max drawdown
