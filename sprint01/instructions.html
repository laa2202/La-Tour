THE MANDATE

Your objective.

This week, investigate whether a systematic trend-following strategy can produce useful investment signals across four financial markets. Learn to retrieve market data, calculate signals, simulate historical performance, identify weaknesses, and defend a research recommendation.

Success means credible, reproducible research — not the highest possible historical return. Every group starts from the same baseline and investigates a different question.

STEP / 01

Understand the Strategy.

What are we researching?

We are testing a simplified version of Time Series Momentum (Moskowitz, Ooi and Pedersen, 2012): whether past positive price trends contain useful information about future market behavior. Our task is to investigate the evidence, not assume the hypothesis works.

ETFMarket exposure
SPYU.S. equities
IEFIntermediate U.S. Treasury bonds
GLDGold
UUPU.S. dollar

How the baseline works

Each month, look at each ETF's return over the previous 252 common trading days, using information available as of the previous close. If its trailing return is positive, target a 25% allocation; otherwise target 0%. Unallocated money stays in cash.

Example: If SPY and GLD have positive signals and IEF and UUP have negative signals, allocate 25% to SPY, 25% to GLD and 50% to cash.

The baseline rebalances monthly, charges 5 basis points × absolute portfolio weight turnover, assumes cash earns 0%, and does not permit shorts or leverage. The previous-close execution convention is a simplified, non-executable research assumption.

What is a signal?

A signal is a rule-derived indicator that informs an allocation: positive trend → eligible for a long allocation; non-positive trend → no ETF allocation. A negative trend is not a short sale in this exercise.

STEP / 02

Set Up Your Environment.

Every analyst must install and run the reference implementation before changing the research code.

2.1 Clone the repository

git clone https://github.com/laa2202/La-Tour.git
cd La-Tour/sprint01

2.2 Create a Python environment

python3 -m venv .venv
source .venv/bin/activate

Windows users should use the activation command appropriate for their terminal. The environment isolates project dependencies.

2.3 Install dependencies

pip install -r requirements.txt

2.4 Download the price data

python src/download_data.py

The intended dataset contains adjusted daily closing prices from January 1, 2010 through October 9, 2026 (subject to actual availability), with the columns date,ticker,adj_close. Inspect the observations for missing dates, duplicate rows, and instrument coverage.

2.5 Verify a shared dataset

shasum -a 256 data/prices.csv

Record the source, download timestamp, date coverage, and SHA-256 checksum. All teams must use the same frozen version approved by the Co-PMs.

2.6 Run the baseline

python src/backtest.py --input data/prices.csv --output results/base.csv

2.7 Run tests

python -m unittest discover -s tests -v

2.8 If price downloads fail

python src/generate_synthetic_fixture.py
python src/backtest.py --input data/SYNTHETIC_TEST_ONLY_prices.csv --output results/TEST_ONLY.csv

The synthetic fixture is only for checking that code runs, not for evaluating real-world strategy performance. Contact the Co-PMs for the frozen real dataset.

STEP / 03

Reproduce the Baseline.

Before beginning team extensions, every analyst should open src/backtest.py and trace the program from historical price data to portfolio performance.

  1. Locate how historical prices are read and validated.
  2. Find the calculation of daily and trailing returns.
  3. Explain how the 252-day return becomes a momentum signal.
  4. Identify how each signal maps to a 25% or 0% target weight.
  5. Find the monthly rebalance logic, portfolio return calculation, and transaction-cost deduction.
  6. Explain why previous-close execution in the reference simulation is not a feasible live fill assumption.
Required checkpoint: Choose at least one historical rebalance date and explain the observations used, resulting signals, target weights, and subsequent simulated returns. You must understand the reference before modifying it.
STEP / 04

Complete Your Assigned Research.

Team A / Signal Research Cooper · Kaka · Ken

Research question: How does the momentum lookback window affect signal behavior?

  1. Reproduce the original 252-day signal.
  2. Calculate alternative 63- and 126-day trailing-return signals.
  3. Compare the three horizons across the four ETFs and historical periods.
  4. Measure signal stability and switching frequency; consider speed versus noise.
  5. Investigate whether apparent improvements are robust without selecting parameters using held-out test results.
  6. Recommend a horizon for further research, or explain why the evidence is inconclusive.

Ask: Which horizon switches most frequently? Do conclusions change across assets or market regimes? What happens when turnover costs are considered?

REQUIRED FILE results/team_a_signals.csvColumns: date,ticker,signal,lookback

Define the signal values and their timestamps. Negative signals map to cash rather than short positions in the baseline.

Team B / Backtesting & Validation Kai · Jonas

Research question: Can we trust the baseline's reported historical performance?

  1. Reproduce baseline results independently.
  2. Audit signal timing, rebalance timing, return alignment, and look-ahead bias.
  3. Calculate CAGR, annualized volatility, Sharpe ratio, maximum drawdown, and turnover.
  4. Compare cumulative portfolio performance and drawdowns against the supplied benchmark.
  5. Examine transaction costs and unrealistic assumptions about trade execution.
  6. Identify which reported results are credible and which need corrections before further use.

Know your metrics: CAGR measures compounded annual growth; volatility measures return variation; Sharpe relates excess return to volatility (state your risk-free convention); maximum drawdown is the largest peak-to-trough loss; turnover measures changing positions.

REQUIRED FILE results/team_b_metrics.csvColumns: sample,strategy,cagr,volatility,sharpe,max_drawdown,turnover

The reference comparison uses a cost-free constant-weight benchmark, unlike the cost-charged baseline. Explain that mismatch.

Team C / Portfolio Risk Leen · Jana

Research question: Can volatility-aware sizing improve the portfolio's risk profile?

  1. Reproduce the equal-25%-per-positive-signal baseline weights.
  2. Estimate trailing 63-trading-day volatility for each ETF using data available before trading.
  3. Specify inverse-volatility weighting or a capped risk-targeting approach.
  4. Explain normalization, caps, cash allocation, and what happens when an asset's signal switches off.
  5. Compare exposure, concentration, turnover, estimated trading costs, and drawdowns where the alternative has been backtested appropriately.
  6. Discuss whether the approach merits further research and what can go wrong (e.g., unstable estimates or excessive concentration).
REQUIRED FILE results/team_c_weights.csvColumns: date,ticker,weight

Generating alternative weights alone does not constitute a completed portfolio backtest. The reference backtester does not automatically ingest these weights; proper integration requires explicit code changes and tests.

STEP / 05

Validate Your Findings.

Use chronological data rather than randomly intermixing past and future observations.

SamplePeriodPurpose
Training2010–2020Develop hypotheses and candidate models
Validation2021–2023Compare proposed approaches
Held-out test2024–Oct 9, 2026Evaluate selected methods once

Adjust for ETF inception dates and actual data coverage. Never select parameters by optimizing against the held-out test. If you revise the strategy after seeing held-out results, disclose that the test has been contaminated.

  1. Prevent look-ahead: no future information may influence a past trade decision.
  2. Distinguish the original reference strategy from proposed variations.
  3. Record dataset provenance, checksum, assumptions, and experiment date.
  4. Include transaction costs, benchmark limitations, exposure, and drawdowns.
  5. Document failure cases and whether conclusions remain robust across periods.

STEP / 07

Research Defense.

Each team presents for 8 minutes followed by 4 minutes of Q&A.

SlideWhat to cover
1 · HypothesisWhat are we testing, and why might it work?
2 · DataWhat data did we use, and what are its limitations?
3 · MethodHow does the algorithm or research procedure work?
4 · ResultsWhat happened? Include quantitative comparisons.
5 · RobustnessWhich assumptions, costs, and failure cases challenge the findings?
6 · DecisionReject, continue, or validate further — and why?

Every member should understand the team's full methodology, not only the portion they coded. Be prepared to explain equations, choices, and limitations in Q&A.

LA TOUR / RESEARCH PRINCIPLES

Research standards.

We value methodological rigor over attractive backtested returns. Every result must be reproducible, transparent, and evidence-based. Disclose weaknesses, unrealistic assumptions, parameter sensitivity, and possible sources of bias.

A negative result supported by rigorous analysis is a successful research outcome.

No strategies are authorized for live capital deployment during Sprint 01.
