ETFs: SPY = U.S. equity, IEF = intermediate Treasuries, GLD = gold, UUP = dollar exposure. These are imperfect futures substitutes. UUP history and ETF tracking/fees need attention.

## Frozen reference strategy v0.1
- Each ETF: trailing **252 common trading-day** adjusted-price return computed **as of yesterday's close**.
- Positive => 25% target portfolio weight; non-positive => 0%; unused capital stays in cash earning 0 in this toy model.
- No shorting and no leverage. Positions selected monthly on first available trading day.
- Backtest daily close-to-close returns, with prior-day signal only. Each rebalance costs 5bps x absolute portfolio weight turnover. Rebalance implementation assumes trading at yesterday's close; **not executable as written**. Later research must model order timing and slippage realistically (e.g., next-open with actual open prices).
- Compare equal-weight 25% each, daily constant-weight benchmark (also simplified). This benchmark includes no transaction cost and thus isn't apples-to-apples; disclose this.
- No assertion of predictive edge or valid live-trading readiness.
